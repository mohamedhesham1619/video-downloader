======================================
     VIDEO DOWNLOADER - HOW TO USE
======================================

1. Adding Videos (urls.txt)
   To download videos, simply add their links to the "urls.txt" file (one link per line). The tool supports a variety of features just by changing how you type the line!

   Features & Formats:
   
   • Download Full Video: Just paste the link.
     https://youtube.com/watch?v=example
     
   • Choose Quality: Add the resolution (e.g., 720p, 1080p).
     https://youtube.com/watch?v=example 1080p
     
   • Download a Specific Clip: Add a start and end time (HH:MM:SS-HH:MM:SS).
     https://youtube.com/watch?v=example 00:01:30-00:02:45
     
   • Audio Only: Add the word "audio".
     https://youtube.com/watch?v=example audio
     
   • Mix & Match: You can combine them!
     https://youtube.com/watch?v=example audio 00:01:30-00:02:45

   For more advanced features and detailed formatting options, please check the README on the GitHub page!

2. Running the App
   Double-click the downloader executable or run it from your terminal. Follow the on-screen prompts to start your downloads.

   NOTE: The very first time you run the app, it will automatically download necessary background tools (yt-dlp, ffmpeg, deno). This may take a couple of minutes depending on your internet connection!
